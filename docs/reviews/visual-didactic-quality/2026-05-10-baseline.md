# Visual Didactic Quality Baseline - 2026-05-10

## Baseline Finding

The current harness can generate a valid Beamer PDF and visual artifacts, but
the baseline agent-generated deck is visually and didactically weak.

## Evidence

- The legacy renderer represented slides as `title + bullets`.
- The legacy `render_beamer` path converted `body` text into bullet chunks.
- The generated example compiled and rendered, but the deck slides were mostly
  generic text bullets.
- Source previews from the selected bioimage book contained strong color
  microscopy imagery, but the deck did not embed those images.

## Root Cause

The agent did not have a useful rendering language. It could choose source pages
and text, but the MCP render contract forced the output into a default Beamer
itemize structure. Prompt improvements alone cannot fix that limitation.

## Acceptance Bar Going Forward

A visual academic deck is not acceptable merely because it compiles. It must:

- use visual source evidence when available;
- vary layout by teaching purpose;
- keep claims short and source-backed;
- render PNG previews and at least one relevant zoom crop;
- pass MCP stdio validation for any MCP-facing change.
